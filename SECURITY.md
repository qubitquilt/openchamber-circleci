# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request. Use [GitHub's private vulnerability report form](https://github.com/qubitquilt/openchamber-circleci/security/advisories/new) so the maintainers can investigate and coordinate a fix privately.

If you cannot access the form, email [michael@qubitquilt.com](mailto:michael@qubitquilt.com). Include the affected version, steps to reproduce, and any relevant impact. Please allow maintainers reasonable time to investigate before public disclosure.

## Supported versions

Security fixes are made on the latest version on the `main` branch. There are no separately maintained release branches at this time.
