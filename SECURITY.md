# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository (the **Security** tab → **Report a vulnerability**) so the maintainers can investigate and coordinate a fix privately.

If private vulnerability reporting is unavailable, contact the repository owner through GitHub privately. Include the affected version, steps to reproduce, and any relevant impact. Please allow maintainers reasonable time to investigate before public disclosure.

## Supported versions

Security fixes are made on the latest version on the `main` branch. There are no separately maintained release branches at this time.
